# Contributing to mu-excel-toolbox

Thank you for your interest in contributing! This project is part of the Meituan CatDesk Skills ecosystem.

## How to Contribute

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add some amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Development Guidelines

- Python 3.8+ required
- Follow PEP 8 style guide
- Test your changes with real Excel files before submitting
- Update documentation if you add or modify features

## Reporting Issues

Please use GitHub Issues to report bugs or request features. Include:
- Excel file format (xlsx, xlsm, csv, tsv)
- Steps to reproduce
- Expected vs actual behavior
- Error messages (if any)
