# 模板目录

此目录存放 Excel 模板文件，供 `template_fill.py` 使用。

## 使用方法

1. 将模板 Excel 文件放入此目录
2. 模板中使用 `{{字段名}}` 作为占位符
3. 调用 `template_fill.py --template templates/xxx.xlsx --data data.csv`

## 占位符语法

- 基础：`{{姓名}}` — 替换为数据中"姓名"列的值
- 嵌套：`{{部门.名称}}` — 支持嵌套字段（JSON 数据源）
- 字段名必须与数据源列名完全一致（含大小写）

## 注意事项

- 模板中的样式（字体、颜色、边框等）会被保留
- 占位符可以放在任何单元格中
- 同一单元格可以包含多个占位符，如 `{{姓名}} - {{部门}}`
